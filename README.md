# 2ch Media

Tampermonkey-скрипт для удобного просмотра вложений в тредах 2ch.

Добавляет вкладку **«Медиа»** рядом с «Избранное» и «Топ тредов». В ней собраны фото, видео и обычные ссылки из сообщений.

Что есть:

- фото и видео сеткой до 6 в ряд;
- поиск фото через Яндекс и Google Lens;
- переход к исходному посту;
- открытие и скачивание файла;
- список ссылок с возможностью раскрыть сообщение;
- сортировка «сначала новые / старые»;
- автоматическое обновление при появлении новых постов.

## Установка

1. Установить Tampermonkey.
2. Открыть [`2ch-media.user.js`](https://raw.githubusercontent.com/shurik2111/2ch-media/main/2ch-media.user.js).
3. Подтвердить установку скрипта.

Скрипт работает на страницах тредов `2ch.org`, `2ch.su` и `2ch.life`.
